# Results

Generated by `python3 lab/summarize.py` from the raw harness output. Method: [`../docs/REPORT.md`](../docs/REPORT.md#3-测试方法).

| File | One row per |
|---|---|
| `bench.csv` | Replay benchmark run (`bench.mjs`): one recorded 122 s answer streamed into a 9-turn math chat while scrolling and typing. |
| `scenarios.csv` | Run of reload / full-chat scroll / idle typing (`scenarios.mjs`). |
| `qa.csv` | Correctness check (`qa.mjs`). |
| `live-baseline.csv` | Turn of the real 8-turn conversation without extensions (`baseline.mjs`; turn 6 timed out). |
| `logs/` | Console logs of each batch, chat ids replaced with `<id>`. |

Main `bench.csv` columns: `blocked_s` = sum of Long Animation Frame blocking time; `frame_p95_ms`
from a rAF loop; `key_*` = keydown to next painted frame; `loaf_*` = long-frame time split into
render-phase style+layout, script-forced style+layout and script; `answer_sha` must be
`043dc8afaf8d` for every run.

Variant names: `baseline`, `*-baseline*`, `smoke` = ChatGPT without extensions. `turbo-v5`,
`cmp-turbo*` = the shipped extension. `oss-*` = other extensions from the survey. `cmp-sb-*` =
Speed Booster Toolkit 4.6.1 (`cmp-sb-default` was first logged as `cmp-sb-limit1`; see the note at
the top of `logs/matrix-sb.log`). `trace-*` runs also recorded a Chrome trace, which slows them
down; don't compare them with the rest. Other names are the ablation variants in `lab/variants/`.
